BULK ENROLLMENT

Import student records

Use this when the school is ready to load its existing student list. The import does not create pretend records.

CSV format

The first row must contain these column names exactly:

studentcode,firstname,lastname,classname,section,schoolname,principalname,academicyear,feerequired,feepaid,uniformstatus
  • S1–S3: leave section empty.
  • S4–S6: section must be MCB, PCB, or MCE.
  • Fee amounts are whole RWF amounts.
  • Existing student code + academic year records are skipped.
  • Invalid rows are reported rather than silently accepted.
